# Trading research skill router

| Request | Skill |
| --- | --- |
| Market data or prices | `skills/trading-data/SKILL.md` |
| Ticker analysis or report | `skills/trading-analysis/SKILL.md` |
| Backtest or strategy | `skills/trading-backtest/SKILL.md` |
| Research notes or workspace | `skills/trading-research/SKILL.md` |
| Signals or paper trading | `skills/trading-signals/SKILL.md` |

Read only the needed skill. Default flow: data -> analysis -> backtest, passing files through `out/`.
Backtest and paper trading only; never place live orders. State fees, slippage and date range.
Use `.NS` for NSE and `.BO` for BSE. Keep replies short; do not claim profitability.
Research only; not financial advice.
