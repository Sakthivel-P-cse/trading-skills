# Trading research skills

A Markdown-first Codex skill pack for market data, analysis, backtests, notes and paper trading. Install Git, Codex and `uv`, then:

```sh
git clone <url> && cd <repo> && ./install.sh && codex
```

Examples: “Fetch RELIANCE.NS daily prices for a year”; “Analyze NVDA”; “Backtest this strategy”; “Review these paper signals”. Packages are installed on demand, not during setup.

Upstreams:
